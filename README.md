# Rhythm Redux

I want to recreate the website at:

https://rhythmstudio.onrender.com/

Build a modern, production-quality website inspired by and closely matching the visual design, layout, spacing, typography, colors, animations, and overall UX of this reference website.

IMPORTANT:

Do not create a generic template.

Reproduce the visual hierarchy and design language of the reference as closely as possible.

Make the website responsive for desktop, tablet, and mobile.

Use clean, reusable React components.

Use Tailwind CSS.

Keep the code well organized and easy to modify.

Use smooth transitions and subtle animations where appropriate.

Make sure the page looks polished at 1440px, 1280px, 1024px, 768px, and mobile widths.

DESIGN:

Match the reference site's overall color palette.

Match the typography style, font sizes, font weights, line heights and letter spacing.

Match the navbar/header height, positioning and spacing.

Match the hero section layout and visual hierarchy.

Match section widths, margins, padding and alignment.

Match cards, buttons, borders, shadows, gradients and corner radii.

Match the visual rhythm between sections.

Match hover states and interactive elements.

Use tasteful scroll-based animations without making the site feel slow.

LAYOUT:

Header/navigation

Recreate the navigation structure from the reference.

Responsive mobile navigation.

Sticky/fixed behavior if present in the reference.

Match button styles and spacing.

Hero section

Recreate the exact visual composition and hierarchy of the reference.

Large headline with matching typography.

Supporting text.

Primary and secondary CTA buttons where applicable.

Recreate the main visual/image/background treatment.

Add subtle entrance animations.

Main content sections

Recreate every major section visible on the reference website.

Preserve the same order of sections.

Recreate cards, grids, text blocks, images and decorative elements.

Match desktop and mobile layouts.

Footer

Recreate the footer structure, typography, links, spacing and colors from the reference.

INTERACTIONS:

Add smooth hover effects to buttons and cards.

Add subtle reveal animations as sections enter the viewport.

Add smooth scrolling for navigation links.

Make mobile navigation functional.

Ensure buttons and links have appropriate hover/focus states.

QUALITY:

Avoid excessive rounded cards or unnecessary gradients unless they exist in the reference.

Do not invent unrelated sections.

Do not use placeholder lorem ipsum.

Use realistic content based on the reference site's purpose.

Ensure excellent visual spacing and alignment.

Ensure accessibility and semantic HTML.

Optimize images and avoid unnecessarily large assets.

Before finishing, compare the implementation visually against the reference and refine:

typography

spacing

colors

element sizes

alignment

responsive behavior

animations

navbar

hero section

cards

footer

The goal is for the finished website to feel like the same design system as the reference website, not merely a website with similar content.
